# Astronomical Smart Switch

یک کلید هوشمند مبتنی بر ESP8266 که با محاسبات نجومی دقیق، زمان طلوع و غروب آفتاب را تشخیص داده و به صورت خودکار رله را کنترل می‌کند.

## ویژگی‌ها

- 🌅 محاسبه خودکار زمان طلوع و غروب آفتاب بر اساس موقعیت جغرافیایی
- 🌐 اتصال به WiFi و دریافت زمان دقیق از سرور NTP
- ⚡ کنترل رله بر اساس زمان‌های نجومی
- 🔧 قابلیت تنظیم موقعیت جغرافیایی (عرض و طول جغرافیایی)
- 📊 نمایش وضعیت و زمان‌ها در Serial Monitor
- 🔄 به‌روزرسانی خودکار محاسبات در هر روز

## سخت‌افزار مورد نیاز

- برد ESP8266 (NodeMCU، Wemos D1 Mini یا مشابه)
- ماژول رله 1 کاناله
- منبع تغذیه 5V
- سیم‌های اتصال

## نصب و راه‌اندازی

### 1. نصب کتابخانه‌ها

کتابخانه‌های زیر را از Library Manager آردوینو نصب کنید:

- `ESP8266WiFi`
- `NTPClient`
- `WiFiUdp`
- `TimeLib`

### 2. تنظیمات WiFi

در فایل کد، اطلاعات WiFi خود را وارد کنید:
```cpp
const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";

### 3. تنظیم موقعیت جغرافیایی

عرض و طول جغرافیایی محل خود را تنظیم کنید:

cpp
float latitude = 35.6892;   // عرض جغرافیایی (مثال: تهران)
float longitude = 51.3890;  // طول جغرافیایی

### 4. اتصال سخت‌افزاری

- پین رله: `D1` (GPIO5)
- می‌توانید در کد تغییر دهید:

cpp
#define RELAY_PIN D1

## نحوه استفاده

1. کد را روی ESP8266 آپلود کنید
2. Serial Monitor را با baud rate 115200 باز کنید
3. برد به WiFi متصل می‌شود و زمان را دریافت می‌کند
4. زمان طلوع و غروب محاسبه و نمایش داده می‌شود
5. رله به صورت خودکار در زمان غروب روشن و در طلوع خاموش می‌شود

## توضیحات فنی

### محاسبات نجومی

پروژه از الگوریتم‌های نجومی استاندارد برای محاسبه زمان طلوع و غروب استفاده می‌کند که شامل:

- محاسبه Julian Day
- محاسبه زاویه ساعتی خورشید
- تبدیل زمان UTC به زمان محلی
- در نظر گرفتن معادله زمان (Equation of Time)

### دقت زمانی

- دریافت زمان از سرورهای NTP با دقت بالا
- به‌روزرسانی خودکار در هر روز
- جبران اختلاف ساعت محلی با UTC
